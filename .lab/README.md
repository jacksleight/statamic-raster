# Statamic Raster Lab

Development lab for [`jacksleight/statamic-raster`](../statamic-raster) and [`jacksleight/laravel-raster`](../laravel-raster), both pulled in over composer path repositories so edits in either package are live here.

Runs at http://statamic-raster--lab.test/ (Herd parks `~/Packages`). Log in at `/!/skip/admin`.

A `tests` collection whose entries cover each publishing state, raster views in `resources/views/raster/` exercising automatic mode, manual mode, caching, data-only rendering and Blade, and a `demos` collection of Brighton places whose share cards are the marketplace showpiece.

See `CLAUDE.md` for the full layout.
